# Combined hedge — multi-pair deployment

## Thesis

The accumulating hedge works best in ranging markets and suffers
in strong trends. Running on multiple uncorrelated pairs simultaneously
diversifies: when one pair trends (accumulated loss), others range
(batch close profit). The combined equity curve is smoother.

## Base

Use the validated combined hedge v5 with dynamic lot sizing (v1).
Each pair runs independently with its own state, positions, and
magic number.

## v1: Major pairs

Run simultaneously on 3 major pairs:
- EURUSD (MagicNumber = 408501)
- GBPUSD (MagicNumber = 408502)  
- USDJPY (MagicNumber = 408503)

Each pair gets 1/3 of the risk allocation:
  RiskPctPerLot = 0.17 (0.5 / 3)

All other parameters identical per pair.

Implementation: single EA attached to each chart separately,
differentiated by MagicNumber. No cross-pair logic needed.

## v2: Low correlation pairs

Choose pairs with historically low correlation:
- EURUSD (MagicNumber = 408511)
- AUDJPY (MagicNumber = 408512)
- GBPCHF (MagicNumber = 408513)

Same risk split: RiskPctPerLot = 0.17 each.

## v3: Single pair control

Run on EURUSD only with full risk (RiskPctPerLot = 0.5).
This is the control to compare against multi-pair.
If multi-pair Sharpe > single pair Sharpe: diversification helps.

## v4: Risk-weighted by spread

Different lot sizes based on typical spread:
- EURUSD (spread ~0.5 pip): RiskPctPerLot = 0.25
- GBPUSD (spread ~1.0 pip): RiskPctPerLot = 0.15
- USDJPY (spread ~0.8 pip): RiskPctPerLot = 0.10

Lower risk on wider spread pairs (spread eats more of H=5 harvest).

## Testing approach

Each pair must be backtested separately in MT5 (multi-pair tester 
is limited). After individual backtests:
1. Export each pair's daily P&L to CSV
2. Combine in a spreadsheet to simulate portfolio equity curve
3. Calculate combined Sharpe, max DD, correlation matrix

## Key metrics per pair
- Monthly return %
- Max DD %
- Sharpe ratio
- Number of MaxFloatingLoss kill triggers
- Correlation of daily returns with other pairs

## Notes
- USDJPY has different pip calculation (2 decimals vs 4)
  HarvestPips may need adjustment (5 pips EURUSD = 50 points,
  5 pips USDJPY = 50 points, but different $ value per pip)
- Swap costs vary significantly by pair — check Tickmill swap rates
- The MagicNumber separation is critical — each pair must track
  its own positions independently
- Start with v1 (majors) for simplicity, only try v2 if v1
  shows high correlation between pairs
