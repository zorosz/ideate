# /session-load — Load Previous Session

Read the most recent session summary and continue from where you left off.

## Steps

1. Find the most recent file in the `sessions/` folder (by date)
2. Read its contents
3. Summarize briefly:
   - What was worked on last time
   - What's the next step
4. Ask: "Shall we continue with this, or do you have a different plan?"

## If there's no sessions/ folder or it's empty

Report: "No previous session found. What should we start with?"
